# Templates

Reusable structures for every content type in this knowledge base. Copy the template, replace the bracketed fields, delete the guidance comments.

## Universal rules

1. **YAML front matter on every file.** `title`, `canonical` (if a public URL exists), `entity`, `doc_type`, `last_updated`. Retrieval systems read these as structured metadata.
2. **A bold `**Summary.**` paragraph directly under the H1.** Self-contained, 2–4 sentences, answering the page's question without requiring the rest of the page. This is the chunk most likely to be retrieved and quoted in isolation.
3. **Facts in tables, arguments in prose.** Tables extract cleanly into structured output; prose carries reasoning. Do not put a number in prose that is not also in a table.
4. **Every entity expanded on first use.** "Tricog CardioCheck (TCC)", never bare "TCC".
5. **A `## Related` block at the end** with 3–5 links. Link structure is how retrieval systems infer relationships.
6. **Never restate a performance figure without its confidence interval.**
7. **Mark unknowns as `**DATA GAP**`** rather than omitting or estimating them.
